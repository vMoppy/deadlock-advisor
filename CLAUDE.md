# Notes for this repository

This is the published web version of the Deadlock Item Advisor (GitHub Pages, from `site/`). Don't edit it by hand:
the tool is developed and tested in the private repository vMoppy/deadlock-item-advisor, and released versions are
copied here with that repository's `tools/publish-web.sh`. The one hand-made part is the Feedback issue form in
`.github/ISSUE_TEMPLATE/`: the advisor's Feedback button pre-fills its fields `area`, `details` and `context` (keep those ids).

The owner is Moppy. Never put their real name, Steam account or match records in this repository: it is public.
